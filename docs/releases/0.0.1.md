# SysML 0.0.1 — development prerelease

This is an early development build. The `0.0.x` series is published as prereleases;
it is not an official stable release or a claim of complete SysML conformance.

## Standalone CLI

- `sysml parse` checks SysML v2 and KerML syntax/body structure.
- `sysml validate` runs the shared kernel's reference and semantic checks.
- `sysml inspect` exports the versioned semantic JSON snapshot.
- Files, recursive directory inputs, stdin, readable diagnostics, JSON reports,
  and CI exit codes are supported. `sysml-inspect` remains compatible.
- Use `--warnings-as-errors` for CI gates that must reject unresolved references,
  which currently have warning severity in the kernel.

Download the archive for Apple Silicon macOS, Intel macOS, Linux x86-64, or
Windows x86-64. Extract it and add its `bin` directory to PATH. No viewer,
Node.js, or runtime library download is needed. SHA-256 checksums are included.
These binaries are unsigned; the macOS builds are not notarized.

## Scope and limits

The source also contains the cross-platform viewer, semantic zoom, type hierarchy,
and inherited-structure views. The attached binary assets in this release are
the standalone CLI. Viewer packages continue to be built by the desktop CI job.

Parsing currently exports diagnostics, not an AST. Validation is limited to the
implemented checks. Workspaces are limited to 32 documents, 5 MB per file and
20 MB total. See the repository's CLI guide and conformance documentation.
