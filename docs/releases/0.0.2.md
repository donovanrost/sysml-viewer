# SysML 0.0.2 — development prerelease

This release improves scalar validation in the shared SysML/KerML kernel.
The `0.0.x` series remains a development prerelease, with no claim of complete
SysML v2 conformance.

## Kernel fixes

- User-defined types named `Integer`, `Boolean`, or `String` no longer get
  mistaken for standard-library primitives. Scalar checks use the identity of
  the loaded library declaration, including references through aliases.
- Scalar values are checked against every declared and inherited type
  restriction. A compatible type or a different base order can no longer hide
  an incompatible restriction. Subsetting and transitive redefinition retain
  those restrictions.
- Unknown scalar classifications and exhausted analysis budgets remain unknown.

Regression coverage now includes these cases in both SysML and KerML, along with
typed member chains, private and missing members, quoted keywords, document-order
independence, and exact large integer bounds through JSON serialization.

## Validation

The kernel changes passed 137 conformance cases (1,258 assertions), 124 Rust
workspace tests, 699 dependency regression tests, and 24 native/WebAssembly
integration tests on macOS. The production web build, Clippy, formatting,
contract checks, and dependency integrity checks also passed. Release builds
rerun the CLI and kernel contract tests on all four supported binary targets.

The internal engine version is `open-mbee/0.10.2@821221767c3c+sysml-kernel.25`.
The public snapshot schema remains version 4.

## Downloads and limits

Attached archives contain the standalone `sysml` CLI, the compatible
`sysml-inspect` executable, documentation, notices, and SHA-256 checksums for
Apple Silicon macOS, Intel macOS, Linux x86-64, and Windows x86-64.
Viewer packages are produced separately as desktop workflow artifacts.
The binaries are unsigned; macOS builds are not notarized.

Scalar incompatibilities retain warning severity. Use `--warnings-as-errors`
when validation should fail on warnings. These checks cover scalar partitions
and integrality, not arbitrary subtype predicates or complete language semantics.
A clean diagnostic report is not proof of full conformance. Workspace limits
remain 32 documents, 5 MB per file, and 20 MB total.
